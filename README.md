# 💰 Income & Expense Tracker

A simple full-stack **Income & Expense Tracker** built with **Node.js, Express, MySQL (or MongoDB)** on the backend and **React + Chart.js** on the frontend.  
It allows users to **track their income, expenses, trends, and category-wise spending** with interactive charts.

---

## 🚀 Features

- 📊 **Track Income & Expenses** — Add and view transactions with date, category, and amount.
- 📈 **Monthly Trends Chart** — Visualize income and expense trends over time using Chart.js.
- 🗂 **Category-wise Expense Summary** — See where your money goes with grouped expense data.
- 🔄 **Real-time Updates** — Transactions update instantly without page reload.
- 🛠 **Backend REST API** — Built with Node.js + Express.
- 💾 **Database Support** — Works with MySQL or MongoDB.
- 🎨 **Responsive UI** — Built with React & Tailwind CSS.
